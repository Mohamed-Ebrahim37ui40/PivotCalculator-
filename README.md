## 2. الميزات

- حساب نصف القطر والمساحة بمعادلة بيرو
- توزيع تلقائي لعدد الجرر على العجلات
- حساب مساحة كل عجلة بدقة (صيغة arcsin)
- دعم ماركات: Zimmatic، Valley، Western + إدخال يدوي
- أربعة تبويبات: المساحة، معدل الزراعة، معدل الحصاد، الاحتياجات
- تبديل اللغة (عربي / إنجليزي) مع حفظ التفضيل
- تبديل الثيم (نهار / ليل) مع حفظ التفضيل
- قابل للتثبيت على الهاتف وسطح المكتب
- تحديث فوري للأرقام عند أي تغيير

## 3. المعادلات (معادلة بيرو)

جميع الحسابات مستمدة من ملف Excel المرجعي:

### نصف القطر من المساحة
```
R (متر) = √(المساحة بالفدان × 4200 / π)
```

### المساحة من نصف القطر
```
المساحة (فدان) = π × R² / 4200
```

### المساحة التراكمية عند مسافة D من المركز
```
θ = degrees(asin(D / R))
H = (2 × θ × المساحة_الكلية / 360) + (cos(radians(θ)) × R × D / 4200)
```

### مساحة العجلة (الحلقة)
```
مساحة_العجلة = H(outer) − H(inner)
```

### عدد الجرر الإجمالي
```
إجمالي_الجرر ≈ R / عرض_الجرة    (عرض الجرة الافتراضي = 1.8 م)
```

### عدد الأبراج
```
عدد_الأبراج ≈ R / طول_البرج
```

العجلة الأخيرة تحصل على المتبقي من الجرر (≤ 31 جرة عادةً).

## 6. التبويبات الأربعة

### ① حساب المساحة
- إدخال مساحة البيفوت فقط
- اختيار الماركة
- جدول العجلات: رقم العجلة | عدد الجرر | المساحة
- يبدأ بـ 9 صفوف ويزيد تلقائيًا
- المساحة الإجمالية أسفل الجدول

### ② معدل الزراعة
- متوسط وزن الجامبو (كجم)
- إجمالي عدد الجامبوهات
- الناتج: كمية التقاوي (طن) ومعدل الزراعة (طن/فدان)

### ③ معدل الحصاد
- عدد الجامبوهات المحصودة
- الناتج: معدل الحصاد (جامبو/فدان)

### ④ احتياجات الزراعة والحصاد
- **الزراعة:** متوسط الوزن (طن) + المساحة + المعدل → عدد الجامبوهات والكمية
- **الحصاد:** معدل الحصاد + المساحة + حمولة السيارة → عدد الجامبوهات وعدد السيارات

## 7. صفحة الاختيار اليدوي

عند اختيار «اختيار آخر» من قائمة الماركات:
1. يُفتح جدول قابل للتعديل (عدد الجرر + طول البرج)
2. زر «ملء تلقائي» يوزع القيم حسب المساحة
3. زر «حفظ ومتابعة» يعيد الحساب في الواجهة الرئيسية
